# go-geoh
[![Go Reference](https://pkg.go.dev/badge/github.com/hsrodriguez/go-geoh.svg)](https://pkg.go.dev/github.com/hsrodriguez/go-geoh)

Find the geohashes that intersect with the given geoJSON

Based on the Python library [geoh](https://github.com/mathieuripert/geoh).

## Installation
`go get github.com/hsrodriguez/go-geoh`

## Usage
`geohashes = geoh.geohashes(geojson, precision, start_precision)`
